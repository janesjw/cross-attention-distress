## 第一步：原稿结构是否成立

原稿 4.3 节先将年度、季度和文本分别压缩为一个 128 维向量；4.4 节再对每一对向量做注意力。若每条路径只有一个 Key，softmax 的归一化轴只有一个元素：

\[
\operatorname{softmax}([qk^T/\sqrt{d_k}])=[1].
\]

因此，该路径只能输出变换后的 Value，不能根据 Query 在多个内容之间选择。实际测试得到：权重全部为 1；改变 Query 后输出最大差值为 0；对 Query 的梯度最大值为 0。这是对原稿所描述结构的核验，不等于找到了原始代码里的同一错误。

原稿的门控文字声称随样本变化，但公式仅给出 `α=softmax(w)`。如果 `w` 只是一个全局可学习参数，就只会得到全体样本共享的权重，不能支持该文字解释。

本次保留 `manuscript_singleton` 作为上述解释的对照，并实现以下修正版：

| 路径 | Query | Key/Value | 每条输出 |
|---|---|---|---|
| 年度→文本 | 年度最后一个 Transformer 状态 | 所有非 padding 的文本隐藏状态 | 128 维 |
| 季度→文本 | 最后一个 LSTM 状态 | 所有非 padding 的文本隐藏状态 | 128 维 |
| 年度→季度 | 年度最后一个 Transformer 状态 | 4 个季度 LSTM 状态 | 128 维 |

三条原始向量加上三条交互向量仍组成六路特征。门控改为 `softmax(MLP(concat(f1,…,f6)))`，从当前样本的六路特征计算六个权重，再求加权和。它保留原稿方向及融合逻辑，但属于本次修正，必须重新训练验证效果。

在真实中文 FinBERT 权重、128 维公共空间和 512 token 输入长度下，完整模型共 103,207,367 个参数，其中语言编码器 102,267,648 个。三个注意力权重张量形状分别为 `[2,4,1,512]`、`[2,4,1,512]`、`[2,4,1,4]`，padding 权重为零；文本嵌入和门控均获得非零梯度。这里的 batch size 2 只用于软件检查，财务输入和标签为明确标识的合成测试数据，未更新训练权重。

实现依据为 [PyTorch 2.8 MultiheadAttention 文档](https://docs.pytorch.org/docs/2.8/generated/torch.nn.MultiheadAttention.html)。这些测试支持进入实现整理阶段，不支持声称新模型优于原模型。

## 第三步：已经明确的复现口径

预测时间为每年 5 月 1 日，财务与文本只用中国时区 4 月 30 日结束前公开的信息，随访至下一年 4 月 30 日结束。五年年度输入为 Y−5 至 Y−1；四期季度变化为 Y−1Q2 至 YQ1，需要 Y−1Q1 至 YQ1 五个季度的基础数。

基线三项均核实为不满足后才进入风险集。任一项已满足就排除，剩余不明确的记录待核实。随访事件取首次公开建立条件的日期，不取财年末日期。已排除记录不贴负类标签，后来 ST 也不能将其改成“新发生”的正类。

按用户要求，规则作用于每个预测日期的公司记录；不是永久排除曾经困境的公司。既往困境公司只有在新的预测日期三项基线均明确为不满足时，才可能重新进入风险集。研究目标是相对于该起点的新困境事件，不是公司一生首次困境。

缺失率分母已经确认：年度 5×18=90 个输入值、季度 4×8=32 个输入值分别计算。年度缺失最多 27 个（30%），季度缺失最多 9 个（28.125%）；年度缺失达到 28 个（31.111…%）或季度达到 10 个（31.25%），排除该公司在该预测日期的整条记录。两项均满足仅表示通过缺失率这一关，不等于已符合全部入样条件。来源审阅完成后、任何插补前执行该筛选。

合并净利润包括少数股东损益。非标准审计指财务报表审计意见中标准无保留意见以外的类型；内部控制审计另存，不混入该标签。无损失时“非标审计且亏损”这一合取条件可判为不成立；有损失但审计信息缺失时仍须核实。

年度特征公式为原稿可操作化的新实现：资产和权益平均数用期初期末算术平均；EBIT 取利润总额加费用化利息；费用及资本开支采用支出幅度；季度变化率用有符号的前期值作分母，比例指标也按相对变化率计算。这些处理已显式写入配置，并非找回了当年的计算程序。基本 EPS 与原稿每股代理的取舍可另作稳健性比较。

训练、验证、测试预测年拟沿用 2017–2021、2022–2023、2024–2025，但重新按信息实际可用性执行：训练标签最迟在 2022-04-30 闭窗后可得；模型选择仅用至 2024-04-30 闭窗后可得的验证标签。2024、2025 两年的测试预测共享冻结的模型；本版本不是每年滚动重训。负类须有完整随访，不能仅因预测年已经过去就认定信息完整。

| 项目 | 原稿给出/本次落实 |
|---|---|
| 年度编码器 | 18→128；5 个时点；2 层、4 头、FFN 256、dropout 0.2 |
| 季度编码器 | 8→128；4 个时点；2 层 LSTM、hidden 128、dropout 0.3 |
| 分类器 | 128→64→32→1；GELU、BatchNorm、dropout 0.3；预测阈值 0.5 |
| 目标函数 | 稳定的 logits 版本 focal loss，正类 α=0.75、γ=2 |
| 优化 | AdamW；非文本 1e−3、文本 2e−5；weight decay 1e−4 |
| 停止规则 | 上限 80 epochs；验证 focal loss；patience 10；恢复最佳权重 |
| 新设默认值 | batch 32，种子 42–46，交叉注意力 4 头且 dropout 0，门控 MLP，余弦调度细节 |
| 预处理修正 | 训练集估计 1%/99% 截尾点、行业中位数、均值和标准差；未知行业回退训练总体中位数 |
| 统计输出 | 整数 TP/FP/TN/FN、Accuracy、Precision、Recall、Specificity、F1、ROC AUC、Average Precision、Brier |
| 不确定性 | 同一测试记录上的公司聚类配对 bootstrap；另行多随机种子训练，不将两者混为一项 |

年度和季度分支的时间维都位于预测之前，所以年度编码器在这个五年窗口内使用双向注意力本身不构成使用未来年份；泄漏检查针对真实披露日期。

已实现相同输入下的拼接、仅门控、均匀融合、单模态、去文本对照。传统机器学习比较仍需用新的完整数据重新实现/拟合，并至少使用相同的 90+32 个财务输入；不能继续把原稿的 26 个数值输入基线成绩直接拿来比较。

## 中文 FinBERT 的证据与限制

本次加载 `yiyanghkust/finbert-tone-chinese` 的固定 revision。其[官方模型卡](https://huggingface.co/yiyanghkust/finbert-tone-chinese)说明它基于中文 BERT，在约 8,000 条私有分析师报告句子的情感数据上微调。模型卡中的情感分类指标不是本文的困境预测指标。原稿引用的 [ProsusAI/FinBERT](https://huggingface.co/ProsusAI/finbert) 属于英文模型，不能只改一个名称就将其描述成中文实现。

公开模型仓库创建于 2024-02-06，训练语料的时间截止点不明。因此目前只能称其为固定权重下的回溯研究方案，不能声称 2017 年即可部署同一编码器，也不能排除预训练阶段的信息交叉。以后须明确这项限制，补充适当的中文基础模型对照，或使用能证明训练时间截止点的权重版本。

随机数固定及确定性运算只保证本次指定环境中的检查结果，不能保证跨硬件和版本逐位相同。[PyTorch 可复现性说明](https://docs.pytorch.org/docs/2.8/notes/randomness.html)

## 对正文与审稿风险的直接影响

原稿的计算成本命题只针对三个单 token 的注意力算术，不能迁移为修正后多 token 结构的等成本结论；需要重写复杂度表达或以实际参数、运算量和运行条件报告。门控的凸组合性质成立，但只在固定输入特征下对权重变化给出的界，不自动证明预测稳健或因果解释。Focal loss 的难例重加权也不单独证明少数类获得更大的总体梯度。

旧样本量、类别占比、相关系数矩阵、训练曲线、显著性和性能表暂不作为可核实结果使用。后续需从新冻结数据和逐样本预测重算，不能用原稿数值反推数据以获得相同结果。

审稿人最可能追问的内容包括：样本框是否含后来退市公司；各年基线排除了多少已困境记录；同一事件的三个标签如何重叠；文本与财务披露是否真正可得；中文预训练模型的历史时点限制；修正后的注意力是否优于相同输入的简单融合；多个种子和公司聚类区间下结果是否稳定。这些问题现在有了可保存证据的位置，但还没有全部实证答案。
